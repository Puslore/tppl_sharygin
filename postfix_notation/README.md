# Стековая машина для постфиксной нотации

Программа вычисляет арифметическое выражение, в котором операнды и операции
разделены пробелами. Поддерживаются операции `+`, `-`, `*`, `/` и специальная
операция `~`.

Операция `~` извлекает два верхних операнда. Если оба не равны нулю, программа
кладёт в стек модуль их разности. Если хотя бы один равен нулю, программа
возводит в квадрат сумму **всех** значений в стеке и заменяет весь стек этим
результатом.

## Запуск

Перейдите в директорию `postfix_notation` и выполните:

```bash
make
```

Команда `make` выводит список доступных целей. Чтобы запустить пример, выполните:

```bash
make run
```

По умолчанию запускается пример `3 0 4 ~ 2 ~`. Чтобы вычислить другое
выражение, передайте его через переменную `EXPRESSION`:

```bash
make run EXPRESSION="2 2 + 4 - 4 ~ 2 3 * +"
```

Для каждого шага программа показывает состояние стека, а в конце выводит
выражение и результат.

## Тесты

Из директории `postfix_notation` запустите:

```bash
make test
```
